# Project Documentation — VertiCare AI

This directory houses the comprehensive technical, architectural, and clinical safety documentation for the VertiCare AI clinical decision support system.

## Documentation Index
- `PROJECT_CODE_MAP.md`: End-to-end directory and clinical module code mapping.
- `architecture/`: High-level system topology, sequence diagrams, and module interactions.
- `api/`: REST API specifications, route schemas, and response contracts.
- `database/`: Relational schema diagrams, table definitions, and migration guidelines.
- `ml/`: Model architecture, training methodologies, and explainability mechanisms.
- `computer-vision/`: Eye landmark tracking algorithms and coordinate normalization.
- `deployment/`: Containerization, Docker Compose, and environment configurations.
- `security/`: Authentication, RBAC, IDOR prevention, and clinical safety compliance.
- `privacy.md`: Zero raw video policy, PHI protection, and tenant isolation guarantees.
- `testing.md`: Test execution strategy, coverage breakdown, and verification commands.
